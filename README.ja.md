# CityTypingGame


ランダムに出題される20の地方公共団体名を早打ちするゲームです。

## デモ
https://code4fukui.github.io/CityTypingGame/

## 特徴
- ランダムに出題される20の地方公共団体名を早打ちします
- キーボード入力に対応し、クリックやエンターキーで進めることができます
- ESCキーを押すことでゲームのやり直しが可能です

## データ
- 市区町村名は [address-japan](https://github.com/code4fukui/address-japan) データセットから取得しています

## ライブラリ
- [@2ndPINEW](https://twitter.com/2ndPINEW) の [HiraganaParser](https://github.com/2ndPINEW/HiraganaParser) ライブラリを使用しています

## フォーク元
- 元々は [TypingGame](https://github.com/takerucam/TypingGame) からフォークされました
